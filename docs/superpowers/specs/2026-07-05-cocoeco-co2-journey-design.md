## 1. 背景与目标

cocoeco 是独立环保品牌(与 Carbadia 交易所品牌关联但独立)。官网使命:

1. 讲述环保/碳中和的愿景、理念与未来规划(主);
2. 介绍产品:Carbadia(carbadia.io 碳信用交易所,模拟盘)与 CCRC(碳信用评级鉴赏家);
3. 环保科普内容;
4. 环保行动/社区入口。

流程约定:**先中文主稿文案 → 用户审 → 视觉设计与开发 → 16 语翻译**。

## 4. 信息架构与导航

- 顶部固定:品牌、章节菜单(10 幕直达)、语言切换(16 语)、"去 carbadia.io" CTA。
- 微光进度条:一点微光沿旅程线随滚动移动(可可的痕迹母题,不再用分子图形),亦可点击跳章。
- 阅读模式开关:纯 HTML 长文版(见降级)。
- 所有正文文案位于真实 DOM 覆盖层(SEO/无障碍/翻译均作用于 DOM),3D 仅为舞台。

## 5. 技术架构

- 独立 Next.js 16 应用,位于仓库 `cocoeco/`(全新脚手架;沿用旧版验证过的配置经验:嵌套 worktree 需 `turbopack.root` 锚定、eslint react-hooks@7 React Compiler 级规则)。
- 实时章节:Blender 建模 → glTF → three.js;场景物件可点击弹知识卡。
- 过场:Blender 渲染 WebP 帧序列/视频,**点击推进后定时播放一次**(不再滚动擦除)。
- 设备分档:低端 → 过场退化为静态定妆图淡入淡出、实时章节退化为截图;`prefers-reduced-motion` → 过场跳切、场景静止帧;两者均可随时切换到阅读模式(M1 长页)。
- i18n:复用交易所 16 语 dictionary 模式(`Record<Lang, Dict>`,`LANG_META` 含 RTL),并扩展:词典值允许 `(n)=>string`(复数,Intl.PluralRules)与 `string[]`(逐行浮现旁白,项数可因语言而异);句内强调用 `**…**` 内联标记由渲染层解析;免责声明等法务文本设全站单键。
- RTL(ar):UI 层(进度条/菜单/旅程线/评级刻度)用 CSS 逻辑属性镜像,3D 舞台与预渲染帧不镜像;CTA 箭头由组件渲染并随 RTL 翻转,不入词典;文本内拉丁串包 bdi;数字用西文并处理 BiDi 重排。
- 3D/帧序列资产内一律无文字(牌匾、印章用图形符号),文字信息全部由 DOM 层承担——否则 16 语需 16 套资产。
- metadata/OG 完整;metadataBase 部署时补。

## 6. 内容生产流程

1. 中文主稿(全部幕的标题/旁白/知识卡/CTA/导航/页脚/metadata)→ 文档 `2026-07-05-cocoeco-copy-zh-v1.md` → 用户审;
2. 审定后冻结中文稿 → 视觉与开发;
3. 16 语翻译多智能体并行派发,统一校对(阿拉伯语注意 RTL 与数字方向);随稿派发"翻译工作包"(数据口径附录、数字量级基准——防 es "billón" 千倍误译、Coco 各语言命名规范、"账"母题术语表),详见文案稿末尾《翻译与工程规范》;
4. 占位替换清单:团队成员、行动项目、备案信息、metadataBase。

科学数据一律带口径附录(来源+年份),翻译时数字不改写。

## 7. 非目标(首版不做)

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 混合管线工作量大(实时+预渲染双轨) | 幕内资产 low-poly 风格化;过场帧序列限制分辨率与帧数;先通滚动骨架再逐幕加资产 |
| 16 语翻译量 | 文案冻结后一次性派发;知识卡短文案化;数字/专名表统一 |
| 性能(移动端) | 设备分档 + dynamic import 逐幕加载 + 帧序列懒加载 |
| 科学数字失准 | 数据口径附录 + 事实核查审稿 |
